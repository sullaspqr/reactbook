React Oktatókönyv – statikus Bootstrap weboldal

Oldalak:
- index.html        Kezdőlap
- konyv.html        Termék/könyv aloldal
- rolam.html        A szerző
- kapcsolat.html    Elérhetőség
- regisztracio.html Regisztráció
- belepes.html      Belépés
- style.css         Közös saját stílus

A Bootstrap 5.3.3 CDN-ről töltődik.
A formok jelenleg statikusak; backend/API bekötéshez később hozzáadható.
A könyv borítója jelenleg CSS-mockup, így könnyen lecserélhető a végleges borítóra.
